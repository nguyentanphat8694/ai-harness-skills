- Stack: C# WinForms, DevExpress v16.1 (XtraEditors, XtraBars Ribbon), SQL Server via System.Data.SqlClient, namespace MiniClinic. Third-party assembly Missing.Core.dll (HintPath ..\libs\, not provided).
